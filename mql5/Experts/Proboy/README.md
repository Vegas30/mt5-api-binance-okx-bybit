# Proboy

This directory is the source of truth for the Proboy Expert Advisor.

- `Proboy.mq5` is the maintained source file.
- Compiled `.ex5` files are generated in the MetaTrader terminal and are not stored in Git.
- Do not edit the copy under `AppData\Roaming\MetaQuotes\Terminal\...\MQL5\Experts` directly.

The current source was consolidated from the latest three-lot version found in the terminal on 2026-09-24. Older variants are preserved in the migration backup on `G:`.
